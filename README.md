# quenta

AI エージェントが使うタスク管理の CLI。開発中で、まだ使える状態ではない。

- 使うのはAIエージェント（複数が同時に使う）
- 人は quenta を直接操作せず、AI を通じて管理する（例：AI に「今の残作業は？」と聞く）
- 出力は JSON。ほかのツールと組み合わせたワークフローに組み込みやすくする

## プロジェクトを汚さない

他人と共有するリポジトリでも、個人が試しに導入できるようにしている。

- データはホームディレクトリにだけ置く。プロジェクトのディレクトリにファイルを作らない
- プロジェクトの設定ファイル（`CLAUDE.md`、`.claude/settings.json` など）を書き換えない
- git を前提にしない。git を読むことも書くこともしない
- やめるときは、バイナリとデータのディレクトリを消せば痕跡が残らない

## データの置き場所

`$XDG_DATA_HOME/quenta/`（`XDG_DATA_HOME` が未設定なら `~/.local/share/quenta/`）。

## 開発

開発の進め方（人がソースコードを読まずに、仕様とテストだけをレビューする）は `CLAUDE.md` にある。作業の予定と不具合は [Issue](https://github.com/TadahiroYamamura/quenta/issues) で管理している。
